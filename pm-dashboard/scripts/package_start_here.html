The scheduling rule

This is the whole logic. Everything else in the system serves it.

opening(c,m)  = carry-over from last cycle
closing(c,m)  = opening(c,m) + std_hours(c,m)

hours_due     = closing >= 4000
calendar_due  = months_since_pm >= 12
triggered     = hours_due OR calendar_due

carry_over    = MAX(0, closing - 4000)

What it means in practice

Standard hours accrue per cell from one monthly Excel upload. When a cell crosses 4000, every machine in it gets a work order in that month.

Hours past the threshold carry forward — a cell running hot never loses hours, which over a year is the difference between three cycles and four.

A cell that never reaches 4000 is scheduled anyway after twelve months, and the dashboard says which of the two rules fired.

Two things worth knowing before you start

The monthly upload is the single point of failure

If standard hours stop being uploaded, counters freeze and nothing is ever scheduled — while the dashboard still looks green.

That is why Missing Std Hours Rows has its own KPI, why page 10 exists, and why one of the six flows does nothing but chase the file. Name an owner and a backup on the worksheet before go-live.

Power BI cannot capture data

It is read-only. Every checklist, breakdown, spare request and abnormality is written by the Power App; the dashboard is the analytics layer on top.

The app and the six flows are specified in the documentation, not pre-built — they have to be built in your own tenant. Allow about a week.

If the Power BI project will not open

The .pbip wrapper files are versioned, and Desktop validates each one against a pattern that moves between releases. Every value here is taken from Power BI projects published by Microsoft, and is re-checked on every build. If your Desktop still refuses the project, the model and the report are fine — only the small wrapper files are wrong for your build, and SETUP.md in the 01_Power_BI folder has a five-minute fix that needs no Python: let Desktop write those files, then copy the two definition folders in.

The report theme is imported separately — View ▸ Themes ▸ Browse for themes ▸ theme\PM_Theme.json. Embedding a custom theme inside the project is the most version-fragile part of the format, and importing it takes five seconds.
