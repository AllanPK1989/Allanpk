Check one sticker on a real phone before you print all 30. Generate, then scan the first label off the screen. It must open the Machine Hub page filtered to MC-01-001 — not a list of every machine, and not a sign-in loop that goes nowhere. A wrong sticker takes about a month to notice, and by then it has been scanned two hundred times against the wrong machine.
  1. Load polyester or vinyl sticker sheets, pre-cut 3 × 8 at 50 × 30 mm. Paper does not survive a fuse plant — oil soaks in and the code is gone in weeks.
  2. Print at 100% / Actual size. Never "Fit to page": it shrinks the code below what a phone reads reliably at arm's length.
  3. Use a laser printer. Inkjet runs the moment someone wipes the machine with solvent.
  4. In the print dialog turn headers and footers off and set margins to None, or every label shifts and the pre-cut sheet no longer lines up.
  5. The last page is a fitting checklist. Take it to the floor and tick each machine off as you scan it.
